# MacClean

맥을 깔끔하게 정리해주는 작은 앱이에요. 지우기 전에 항상 무엇을 지울지 보여주고, 대부분은 **휴지통으로만** 옮겨서 되돌릴 수 있어요.

## 할 수 있는 것

- **내 맥**: 칩·메모리·macOS 버전, 저장 공간, 메모리 구성과 압력, CPU 사용률, 배터리 상태·최대 용량·충전 횟수를 실시간으로 확인하고, 메모리를 많이 쓰는 앱을 바로 종료
- **메뉴 막대**: 오른쪽 위에 CPU·메모리·남은 저장 공간을 항상 표시, 클릭하면 상세 패널과 바로가기 (로그인 시 자동 실행 옵션)
- **스마트 스캔**: AI 앱 캐시, 브라우저 캐시, 중복 빌드 폴더, `node_modules` 같은 개발 찌꺼기, 시스템 정크, 오래된 다운로드, 삭제한 앱이 남긴 파일, 대용량·중복 파일
- **개인정보**: 브라우저별 방문 기록·다운로드 기록·자동완성·쿠키 (기본은 전부 해제, 직접 고른 것만)
- **앱 완전 삭제**: 앱과 앱이 남긴 파일까지 한 번에
- **휴지통**: 삭제한 날짜 확인, 정렬, 골라서 완전 삭제, MacClean으로 지운 파일은 원래 위치로 되돌리기
- **자동 업데이트**: 왼쪽 아래 업데이트 버튼 한 번으로 새 버전 적용

## 절대 건드리지 않는 것

- 저장된 **비밀번호**, 키체인, 북마크
- Claude·ChatGPT·Codex 같은 **AI 앱의 대화 이력과 기억**
- 스캔만으로는 아무것도 지우지 않아요. 서버로 보내는 데이터도 없어요.

## 설치

필요한 것: macOS 13(Ventura) 이상, Apple 명령어 도구(무료, 처음 한 번 자동 안내)

1. 이 페이지의 초록색 **Code** 버튼 → **Download ZIP**
2. 터미널에서: 
   ```bash
   cd ~/Downloads && unzip -o macclean-main.zip && bash macclean-main/build.sh
   ```
   or 압축해제된 상태
   ```bash
   cd ~/Downloads && bash macclean-main/build.sh
   ```
   
4. "명령어 도구 설치" 창이 뜨면 설치하고, 끝나면 2번을 한 번 더 실행해요.

설치가 끝나면 `/Applications/MacClean.app`이 열려요. 그다음부터는 앱 안의 **업데이트** 버튼으로 새 버전을 받으면 돼요.

### 권한

휴지통 목록과 Safari 기록을 보려면 **시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 권한**에서 MacClean을 켜주세요.

## 터미널로만 쓰기

```bash
python3 macclean.py --scan-only        # 점검만
python3 macclean.py                    # 골라서 정리
python3 macclean.py --uninstall Zoom   # 앱 완전 삭제
python3 macclean.py --empty-trash      # 휴지통 비우기
```
